# cannonyarder-media

Pictures for cannonyarder.org, served through jsDelivr pinned to a commit, e.g.
`https://cdn.jsdelivr.net/gh/VE5PERS/cannonyarder-media@<commit>/yardle/dalai.webp`.

- `yardle/`: the easter eggs on The Cannon Yardle page: dalai, chenoldone, dalaiqiang (played in that order for
  Poldone, Dalaiquitting or Chenoldone), and miguel (on its own, for Miguel).

Files are addressed by commit, so replacing a picture means a new commit and a new address on the site.
